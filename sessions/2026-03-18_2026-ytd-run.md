# Session 04 — 2026-03-18: Jan–Mar 2026 WA run

## Purpose

Test pipeline against the most recent available data (2026 YTD) and document AWRAL unit behaviour for the new year.

## Run

```bash
uv run python main.py \
  --year 2026 \
  --start-date 2026-01-01 \
  --end-date 2026-03-15 \
  --risk-output-prefix outputs/risk_2026_jan-mar_WA \
  --risk-plot-path outputs/risk_2026_jan-mar_WA.png \
  --silo-variable max_temp \
  --silo-variable vp_deficit \
  --min-lat -35 --max-lat -13 \
  --min-lon 112 --max-lon 129
```

## AWRAL unit change — 2026

`sm_pct_2026.nc` is already in fraction (0–1), max = 0.961. No conversion applied.
`sm_pct_2025.nc` was in percent (0–100) — divided by 100.

The pipeline's heuristic (`max > 1.1` → divide by 100) handles this automatically. Documented in `docs/data-sources.md`.
